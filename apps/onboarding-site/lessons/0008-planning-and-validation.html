Atlas Console · Lesson 8 · 3 min

Changes

Changes shows when an API has changed and which workflows may need an update.

How Atlas labels a change

LabelMeaning
Incompatible contractThe declared contract removes or retypes a field, or adds a required field.
Compatible contractThe declared contract has only structurally compatible additions.
Metadata changedOnly descriptive annotations in the declared contract changed.
Needs reviewThe structural change is ambiguous, or Atlas has runtime evidence without a declared-contract diff.

An incompatible declared contract quarantines new affected intake until an approved migration is activated. Runtime-only evidence awaits source rediscovery. Runs that already started continue with their original version.

Atlas compares the registered OpenAPI or AsyncAPI operation fragment and referenced schemas. It does not inspect service source code, prove runtime behavior, or prove that a deployment matches its declared contract.

Review the impact

A change shows the old and new API action, the fields that changed, and every workflow step that uses it.

Create a fix

Create migration makes a proposed workflow update. Review, test, approve, and activate it in Create Workflow just like any other version.
