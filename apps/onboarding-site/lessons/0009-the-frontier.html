Atlas Console · Lesson 9 · 1 min

Activity

Activity shows who changed something, what changed, and when.

Search for a workflow, capability, run, migration, setting, or person. Select a result to see its history in order.

Each entry includes the person or system that caused it, the environment, the time, and a link to more detail when one is available.

History is not edited

Atlas adds a new entry when something changes. It does not rewrite or delete earlier entries.

Example

If a workflow stops accepting new runs, search for it here. You can see when Atlas found the API change, when it stopped new runs, and who approved the replacement.
