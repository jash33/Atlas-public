Atlas Console · Lesson 10 · 2 min

Settings

Settings controls who can use Atlas and what each environment needs to run workflows.

SectionUse it to
OrganizationSet the name and default environment.
MembersAssign Author, Admin, or Operator roles.
WorkersCheck whether each Worker is connected and compatible.
Secret aliasesName credentials that are stored with the Worker.
Allowed hostsChoose which internet hosts an API action may call.

Atlas does not store credential values

The Console stores a name such as SLACK_BOT_TOKEN, not the token itself. The real value is installed with the Worker and never appears in the Console or Backend.

Who can change settings

Everyone can view the local demo settings. Only an Admin can change them. Each change also appears in Activity.
