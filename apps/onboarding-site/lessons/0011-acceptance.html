Atlas walkthrough · Lesson 11 · 3 min

From request to run

This is the main Atlas workflow from start to finish.

  1. Connect APIs. In Capabilities, add the API definitions Atlas needs.
  2. Describe the integration. In Create Workflow, explain the result you want.
  3. Review the draft. Check the steps, data mappings, retry rules, and credentials.
  4. Test and approve. Run the generated tests. An Admin approves the exact version that passed.
  5. Find and invoke it. In Workflow Catalog, open the workflow in the selected environment. When a version is active, copy the Invoke via API sample POST /ingest request and send it to the matching local gateway. Credentials stay with the Worker.
  6. Review the result. Runs shows each attempt and hides sensitive data. If the run stops, Atlas shows the safe recovery options.
  7. Check the history. Activity shows who created, approved, ran, or repaired the workflow.

The incompatible-contract proof

The focused vertical slice maps Payment fields invoice_id, amount_cents, lowercase currency, and a nested customer notification address into Billing's camelCase, nested, decimal, uppercase contract. Create Workflow shows the generated .atlas.yaml, mapping preview, compiled plan, provenance, signature status, and version diff.

Approval signs the exact sandbox-tested bundle. The customer worker accepts IR versions 1 and 2, verifies integrity and activation before Temporal start, and evaluates the bounded mapping customer-side. The acceptance test records a delayed provider request; after one bundle byte changes, verification fails and the provider side-effect count does not grow.

A breaking destination-schema change names affected mappings but never edits an approved bundle. A newly compiled, sandbox-tested, approved, and signed artifact is required.

The main idea

AI can suggest an integration. Deterministic compilation, tests, human approval, and Worker verification decide what may run.

The workflow artifacts reference separates editable source, compiled IR, signed bundle, and runtime interpretation.
