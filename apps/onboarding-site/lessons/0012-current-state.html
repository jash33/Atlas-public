Atlas walkthrough · Lesson 12 · 2 min

When an API changes

Atlas finds the change, shows which workflows are affected, and sends the fix through normal review.

Follow it in the Console

  1. Capabilities: compare the old and new Billing action.
  2. Changes: see the removed field and affected workflow.
  3. Create Workflow: review, test, approve, and activate the fix.
  4. Workflow Catalog: find the stable workflow and compare its active and latest versions.
  5. Runs: compare a run before the change with one after it.
  6. Activity: see the full history.
