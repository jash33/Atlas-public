Atlas · Reference

Glossary

Short definitions for Atlas terms. You do not need to learn these before using the product.

ProductCapabilitiesWorkflowsRunsChangesSettings

Product

Atlas
A tool for creating, approving, and running integrations.
Console
The Atlas website.
Backend
The service that stores data, checks permissions, and sends work to Workers.
Worker
The customer-side service that holds credentials and runs workflows.
environment
A separate place to run workflows, such as Development or Production.
control plane
The Console and Backend.
customer execution boundary
The Worker and the customer systems it can reach.

Capabilities

capability
One API action Atlas may use, such as getting an invoice.
source
The API document from which Atlas learns capabilities.
discovery
A check of a source for new or changed capabilities.
capability version
A saved version of one API action.
capabilityVersionId
The unique ID for a capability version.
provenance
A record of where information came from.
planner projection
The small set of approved capability facts the AI model may use.
capability pin
The exact capability version used by a workflow or run.
safety annotation
A fact supplied by a person, such as whether an action is safe to retry.

Workflows

workflow
An integration authored and saved in Atlas. Connecting or ingesting a capability source does not create workflows.
.atlas.yaml
The editable, human-readable authoring source for a workflow. A Worker never executes it directly.
Workflow IR
The closed, typed data that Atlas compiles from authoring source and interprets at runtime.
transformation AST
The bounded data language used to map one capability's output into another capability's input without arbitrary code.
workflow version
A saved workflow that does not change. Editing creates another version.
irHash
A fingerprint used to detect changes to a workflow.
.atlas bundle
The immutable, approved, signed UTF-8 JSON artifact verified by the Worker.
artifact
A fixed execution package with its own identity. The signed .atlas bundle is the current workflow artifact.
sandbox evidence
The test results for one workflow version.
approval
An Admin's decision that one tested workflow version may run.
activation
Choosing the approved version that new runs will use.
rollback
Choosing an older approved version for future runs.
projection fingerprint
A fingerprint of the capability facts used to create a draft.

Runs

run
One execution of a workflow.
run command
The job the Backend makes available to a Worker.
ExecutionGrant
A short-lived signed permission for a Worker to run one approved workflow.
bundle verification
The Worker's fail-closed check of a bundle's signature, identity, pins, approval, activation, and grant before Temporal starts.
delivery ID
An outside ID used to prevent the same request from starting twice.
idempotency
The ability to repeat a request without causing the same effect twice.
parked
A run that has stopped and needs a person to choose what happens next.
repair
An approved action that lets a parked run continue or end.
resume
Continue a run from its saved history.
compensation
An action that tries to undo an earlier action.
irreversible boundary
The point after which Atlas cannot fully undo completed work.

Changes

drift
A difference between an approved API version and newly found information.
change classification
Atlas's bounded declared-contract label for a change: Incompatible contract, Compatible contract, Metadata changed, or Needs review.
blast radius
The workflows and steps affected by a change.
quarantine
A block on new runs while an unsafe change is reviewed.
migration
A proposed workflow update for a changed API.

Settings

Author
A person who creates workflows.
Admin
A person who approves workflows and changes settings.
Operator
A person who watches runs and handles failures.
secret alias
A name for a credential stored with the Worker. Atlas does not store the value.
allowed host
An internet host that a capability is permitted to call.
Activity event
A saved record of who changed something, what changed, and when.
