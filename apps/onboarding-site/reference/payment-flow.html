Incompatible API mapping proof

Payment API response
  → rename invoice_id to invoiceId
  → divide amount_cents by 100
  → uppercase currency
  → project customer email
  → Billing API request

The approved mapping is compiled into typed data and signed inside the .atlas bundle. The Worker verifies the bundle, evaluates the mapping customer-side, and records provider-observed timing and side-effect evidence. Changing one bundle byte prevents the Billing call.

API change demo

change the Billing API
  → find the affected workflow
  → stop new runs
  → create and test a fix
  → approve the fix
  → run the new version

Earlier runs keep their original workflow version when a replacement version is activated.
