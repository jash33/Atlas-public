# Issue tracker: GitHub

Issues and specs for this repository live in GitHub Issues under `jash33/Atlas-public`. Use the `gh` CLI
for operations.

## Wayfinding operations

- A Wayfinder map is an issue labelled `wayfinder:map`.
- Decision tickets are GitHub sub-issues of the map.
- Tickets use one of `wayfinder:research`, `wayfinder:prototype`, `wayfinder:grilling`, or
  `wayfinder:task`.
- Native GitHub issue dependencies represent blocking relationships.
- Claim a ticket by assigning it to the driving developer before beginning work.
- Record a decision in a resolution comment, close its ticket, and add a linked gist to the map's
  Decisions-so-far section.
- Marketing-site maps and all their child tickets also receive the `marketing-site` scope label.

## Pull requests as a triage surface

PRs are not a request surface.
