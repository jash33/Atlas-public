# Triage labels

| Role              | Label             |
| ----------------- | ----------------- |
| Needs triage      | `needs-triage`    |
| Needs information | `needs-info`      |
| Ready for agent   | `ready-for-agent` |
| Ready for human   | `ready-for-human` |
| Will not be done  | `wontfix`         |

`marketing-site` is a scope label, not a triage state. Apply it to the marketing-site Wayfinder map
and every child ticket.
