# Marketing-site context

## Marketing Site

Atlas's public, indexable website for explaining the project and its use cases.
It is distinct from the Console and Developer Course.

## Console

The Atlas product application. The Console is where customers use Atlas; it is not part of the
Marketing Site.

## Developer Course

The learning site that teaches the Atlas application. It is separate from reference documentation and
part of the Marketing Site.

## Documentation

Public explanatory and reference material that helps people understand or use Atlas. Documentation
may be linked from or presented alongside the Marketing Site, but it remains a distinct content
surface rather than marketing copy.

## Engineering Manager

The Marketing Site's primary audience: a technically experienced decision maker responsible for
engineering delivery, team effectiveness, and integration risk, without necessarily working in the
implementation details day to day.

## Atlas-managed API workflow

An integration whose lifecycle is managed through Atlas. The term distinguishes workflows and API
dependencies Atlas knows about from integrations elsewhere in an organization that Atlas cannot
claim to govern or protect.

## Reference workflow

A concrete product demonstration used to prove Atlas's lifecycle and guarantees. A reference
workflow is evidence for how Atlas works, not a claim that its business domain defines Atlas's
product category.

## Public Discovery

The Marketing Site's availability to human search engines and agent search through crawlable,
machine-readable public content. It does not imply or guarantee ranking, citation, or inclusion.
